# Staj Görev Takip

Python ile geliştirilmiş, terminal tabanlı bir görev takip uygulamasıdır.

## Özellikler

- Görev ekleme
- Görevleri listeleme
- Görev tamamlama
- Görev silme
- Görev arama
- Git ve GitHub ile versiyon kontrolü

## Kullanılan Teknolojiler

- Python
- Git
- GitHub

## Çalıştırma

Projeyi bilgisayarınıza indirdikten sonra terminalde proje klasörüne gidin:

```bash
python main.py
